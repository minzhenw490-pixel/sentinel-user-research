## 对产品的影响

- 风险提示要用白话 —— 用户看不懂合约提示，需要 AI 用日常语言解释这笔交易在干什么；
- AI 只做建议不做决定 —— 用户保留最终确认权；
- 信任来自可核验 —— 每条风险判断要能说清依据（哪条路径、哪个权限、哪个池子）。
